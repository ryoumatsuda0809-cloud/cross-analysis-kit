# ブランド定義（テンプレート）

> **提出物・対外資料の体裁と言葉づかいは、ここ1箇所で決める。**
> `tougou-report` の出力仕様（§出力仕様(4)）から参照される。
> **★空欄のままPDF化しない。**空欄は「まだ決めていない」という事実であって、既定値ではない。
>
> 使い始めるときに、`{…}` の欄をあなたの事務所の情報で埋めてください。
> **このファイルに実在の住所・連絡先を書いたら、公開リポジトリには push しないこと。**
> （公開したい場合は、このファイルを `.gitignore` に足すか、`{…}` のまま残す）

## 2. 色（既定：深緑）

値の実体は `_report_build/style.css` の `:root`。**ここと食い違ったら style.css が正。**変えるときは両方を直す。

| 用途 | 値 | 使う場所 |
|---|---|---|
| 主色 | `#2f5d50` | 見出しの罫線・h3の文字・番号・引用の左線 |
| 主色の淡色 | `#e5eeea` | 表の見出し背景 |
| 文字色 | `#1f2328` | 本文 |
| 補助の文字色 | `#5b6470` | 注記 |
| 背景の淡色 | `#f5f6f7` | 引用ブロック |
| 罫線 | `#d3d7dc` | 表 |

**選ぶときの基準**
- 提出物はモノクロ印刷されることがある。**色だけで意味を持たせない**
- 装飾で勝負する書類ではない。**色は1色＋グレースケールで足りる**

## 5. 言葉づかい

| | |
|---|---|
| 文体 | 敬体 |
| 相手の呼び方 | **御社** |
| 一人称 | 屋号／本人が書く欄では「私」 |
| **誠実さを宣言しない** | 「正直に書きます」「隠さずに」を**書かない。**誠実さは書きぶりに出るもの |
| 断定しない | 「〜の可能性があります」。ただし**1ページに3回以上続けない。**言い切れる事実は言い切る |
| 押し売りしない | 「続けるかどうかは、御社が決めてください」で終える |
| 現場の生の言葉 | **載せない。**役割と頻度・数値に置き換える（守秘） |
| 資格の独占業務 | 法務・税務・労務・許認可に「〜すべき」と書かない（業際） |

### 禁止語（提出物）

**見立て系**：可能性がある※／思われる／おそらく／〜が課題／〜が弱い／〜が遅れている
　※`06` では格付けに応じて使う。`01`（外形カード）では禁止
**内部語**：実態／自己申告／定規／仮説（封）／棄却／見立て／案件{英字}／`_材料`／実走ログ／SKILL.md

## 7. PDFを作る場所

**`対外資料/_report_build/`**

```bash
cd 対外資料/_report_build
./build.sh <レポートの.md>
```

- **体裁は `style.css` の1箇所だけ**で決まる。md には体裁を書かない
- **`check_report.py` に通らなければ PDF は作られない**（必須節・内部語・誠実さの宣言・未記入欄）
- 使い方は `_report_build/README.md`
