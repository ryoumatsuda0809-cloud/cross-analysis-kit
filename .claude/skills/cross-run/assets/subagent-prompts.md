### ★仕込みメモは、材料ファイルの中に書かない（2026-08-10 追加）

架空案件では「どんな食い違いを仕込んだか」をメモしたくなる。**だが材料ファイルの中に書くと、
①や②がそれを読んで「答え」を先に知る**（実走 #6 で `外から見える顔.md` と `現場メモ.md` の
両方に作業メモが混入し、①が読んだ）。

| | |
|---|---|
| ❌ | `外から見える顔.md` や `現場メモ.md` の冒頭・末尾に「〜という仕掛けを反映した」と書く |
| ❌ | HTMLコメント `<!-- -->` で隠す（**AIには見える**） |
| ✅ | **`_材料/_仕込み_ネタバレ.md` に分離。①〜④が終わるまで開かない** |

**材料ファイルには、その会社について外から/現場で見えることだけを書く。**
「これはテスト用にこう作った」という**メタ情報は、材料ではない。**
