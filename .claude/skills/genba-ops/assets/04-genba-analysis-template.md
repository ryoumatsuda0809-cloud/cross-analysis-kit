## 1. 真因の芽リスト

> 現場の事実から、自分の目で出す。①の仮説を裏付けも反証もしない。**芽の文で事実として書くのは、引いたメモの行が言っていることだけ。**`01` から来た事実や、別々の行のあいだのつながり（〜のせいで・〜以来・〜で入れた）は事実の文に混ぜず、「（`01` による）」「（②がつないだ）」と添えて解釈の側に書く（例：メモが「人が辞めた」「残業が増えた」の別々の2行なら、事実の文で「人が辞めて残業が増えた」とつながない。§2 の「現場の事実」も同じ → 実走 #74）

| # | 真因の芽 | 根拠（**【役割】とメモの行番号**。個人名は書かない） | **強度** | **情報源の役割数** | パック／`01`との整合 | タグ |
|---|---|---|---|---|---|---|
| 1 | | 〔例：【直売担当】L12・L15／【レジ担当】L20〕 | 強／中／弱 | **2役割** | | `#現場オペ` |
| 2 | | | | | | |

> **★根拠は `【役割】L行番号` の形で書く**（2026-09-29／実走ログ #58）。
> - 役割は、**現場メモのその行の頭にある【役割】をそのまま写す。メモに無い役割を書かない**（推測で補わない）
> - 行番号は現場メモの行番号（1から）。範囲でなく1行ずつ（`L12・L13`）
> - **情報源の役割数 ＝ 引いた行の【役割】の種類の数。【不明】は数えない**（全部【不明】なら「不明」と書く）。**【不明】の行も引いたら、括弧で添える**（例：`1役割（＋不明1行）`。数えないので、添えないと話者の分からない根拠が③に見えない → 63-2）。**②が別々の話をつないだ芽（その因果を述べた人はいない）も括弧で添える**（例：`2役割（つないだ）`。添えないと③が「2役割が裏付けた」と読む → 62-4）

> **★「情報源の役割数」を必ず書く**（実走ログ 3-22・52-1）。
> 強度だけでは、役割の広がりと当事者性が1つのラベルに潰れ、**③が代表性を判定できない。**
>
> **この `04` 全体で、何役割から取れたかを冒頭に書く：** 　→ **本件は {n} 役割から取得**
> 1役割しかない場合は、**「設計上の3軸が実質2軸以下」**である旨を §5 に明記する。

> 重みづけに必要なのは「誰が」ではなく「**どの役割が・何回**」。名前は要らない。
>
> **★強度を必ず書く**（2026-08-04 実走 #2 で追加）。書かないと、1名の伝聞が
> 複数人の証言と同じ重さで③に渡り、代表性の判定が③の勘に依存する。
>
> | 強度 | 目安 |
> |---|---|
> | **強** | **その芽そのものを**、複数の役割がそれぞれ直接、複数回（1名の当事者の明言は「中」→ 52-1。**②が別々の話をつないだ芽・伝聞まじりの芽は、役割が複数でも中まで** → 62-4） |
> | **中** | 1名だが、その業務の当事者。または数字を伴う |
> | **弱** | **1名の伝聞**（「みんな言ってる」）／立場が離れた人の推測／こちらが誘導した可能性のある回答 |

> **タグは固定リスト**：`#市場` `#現場オペ` `#財務` `#組織` `#DX`（新タグを作らない）

## 2. 建前と現場のズレ一覧

> `01` §2（建前＝出典付きの事実）と、現場で見た事実の差。**①の仮説とは突き合わせない。**

| # | `01`§2の建前（対外的にどう言っているか） | 現場の事実（末尾に `【役割】L行番号`） | 差分 | **同じものを測っているか** | タグ |
|---|---|---|---|---|---|
| 1 | | | | **はい**／**いいえ（層が違う）** | |

> 現場の事実にも、§1 と同じ形で根拠の行を書く（例：`…している（【工場長】L12）`）。
> 比べて差が無かった建前も表に書く（差分に「**ズレなし**」）。

**比較していない建前（ズレが無かったのではない）：**
- {建前}（`01`§2）…現場メモに対応する事実が無い

> **★現場メモに対応する事実が無い建前は、表に入れず、上の一覧に並べる**（2026-09-29／実走ログ #59）。
> 表の行の「現場の事実」には必ずメモの行番号を書く（上の決まり）。メモに無いものは行にできないので、ここに並べる。
> ③④はこの一覧を「**ズレなし**」と読まないこと。**比べていないことと、比べて差が無かったことは別。**

> **★「同じものを測っているか」を必ず埋める。**
> 数字が両方あっても、**測っているものが違えば並べてはいけない。**
> 例：対外的な「客先に流出した不良率」と、現場の「工程内で止めた不適合率」。
> **片方は"出てしまった数"、片方は"止めた数"。分母も定義も別。**
>
> ここで「いいえ」と書かないと、③④が並べて
> **「公称より実際が悪い＝建前が虚偽」という誤読が成立する。**
> 数字が揃っているぶん、もっともらしく見える（実走 #6 の指摘）。
>
> **「いいえ」なら差分は書かない。** ③の `05`§9-2 へ送る。

### 市場ベンチマークとのズレ

> **★「状態」を必ず埋める。空欄にしない。**
> 空欄のまま渡すと、③④が「**ズレなし＝正常**」と読む（実走ログ 6-7）。
> **比較していないことと、比較して差が無かったことは、まったく別。**

| ベンチマーク（`01`§3） | 現場の数字 | **状態** | 差 |
|---|---|---|---|
| | | 比較できた／**比較不能（両側なし）**／**片側欠測（現場の数字なし）**／**片側欠測（ベンチマークなし）** | |

**★全項目が「比較不能」だった場合は、下に一文で明記する：**

> 市場ベンチマークとの比較は **{n}項目すべて成立していない。**
> 両側またはどちらかの数字が無いためであり、**「業界平均と差が無かった」ではない。**
> ③④はこれを「異常なし」と読まないこと。
